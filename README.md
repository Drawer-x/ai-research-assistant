# AI Research Assistant

AI 驱动的科研文献分析平台，面向学生和科研人员，提供文献管理、AI 阅读、文献关系图和 Agent 科研规划等功能。

## 一、项目模块

- 用户登录注册
- PDF 文献上传与管理
- 文献标签和阅读状态管理
- AI 论文总结
- AI 论文问答
- 文献关系图
- Agent 科研规划
- 多论文对比与综述辅助

## 二、成员分工

| 成员 | 角色 | 主要目录 |
|---|---|---|
| 成员 A | 后端负责人 / 组长 | `backend/`, `docs/design/` |
| 成员 B | AI 模块负责人 | `backend/app/services/` |
| 成员 C | 前端负责人 | `frontend/` |
| 成员 D | 测试与文档负责人 | `docs/test/`, `docs/deployment/`, `docs/sprint/` |
