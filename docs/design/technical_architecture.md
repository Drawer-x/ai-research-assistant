# 技术架构设计

## 1. 总体架构

系统采用前后端分离架构。

用户通过前端页面上传论文、查看文献库、进行 AI 阅读和查看关系图。
后端负责用户认证、文献管理、PDF 解析、AI 调用、关系图数据生成和科研规划生成。
数据库保存用户、文献、标签、AI 总结、文献关系和科研计划等数据。

## 2. 技术栈

| 模块 | 技术 |
|---|---|
| 前端 | Vue 3 + Element Plus |
| 后端 | FastAPI |
| 数据库 | SQLite / MySQL |
| PDF 解析 | PyMuPDF |
| AI | 大模型 API |
| 向量检索 | FAISS / Chroma |
| 关系图 | ECharts Graph |
| 部署 | 本地部署 / Docker |

## 3. 系统模块

- 用户与权限模块
- 文献管理模块
- PDF 解析模块
- AI 阅读模块
- 文献关系图模块
- Agent 科研规划模块
- 综述辅助模块
- 测试与部署模块

## 4. 数据流

1. 用户上传 PDF
2. 后端保存文件
3. 后端解析 PDF 文本
4. 系统保存文献元数据
5. AI 模块生成论文总结
6. 用户基于论文提问
7. RAG 模块检索相关文本
8. 大模型生成回答
9. 前端展示回答和总结
10. 系统生成文献关系图和科研计划
