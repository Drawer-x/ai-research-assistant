# 测试计划

> **项目名称**：AI Research Assistant  
> **版本**：v0.1  


---

## 1. 概述

### 1.1 项目简介
AI Research Assistant 是一个面向学生和科研人员的文献分析平台，提供文献管理、AI 阅读、文献关系图和科研规划等功能。

### 1.2 测试目标
- 验证系统功能是否符合需求规格
- 发现并跟踪软件缺陷
- 确保系统在不同环境下稳定运行
- 验证 API 接口的正确性和性能

### 1.3 测试范围

| 模块 | 测试内容 |
|------|---------|
| 用户认证 | 注册、登录、权限验证 | 
| 论文管理 | 上传、列表、详情、删除 | 
| AI 功能 | 论文总结、论文问答 | 
| 文献关系图 | 关系图生成、交互 | 
| Agent 规划 | 科研计划生成 | 

---

## 2. 测试策略

### 2.1 测试层次

| 层次 | 工具 | 说明 |
|------|------|------|
| 单元测试 | pytest | 测试后端单个函数/方法 |
| API 测试 | pytest + TestClient | 测试 RESTful API 接口 |
| 集成测试 | 手动 + Postman | 测试前后端联调 |
| 端到端测试 | 手动测试 | 模拟用户真实操作流程 |

### 2.2 测试类型

| 类型 | 说明 | 
|------|------|
| 功能测试 | 验证功能是否正常工作 | 
| 异常测试 | 验证错误处理是否合理 | 
| 边界测试 | 验证边界条件（如文件大小限制） | 
| 回归测试 | 修改代码后重新测试 | 
| 性能测试 | 响应时间和并发能力 |
