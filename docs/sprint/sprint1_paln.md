## 6. Sprint 1 完成标准
- 后端启动：执行 uvicorn main:app --reload 后服务正常启动。
- 前端启动：执行 npm run dev 后可以访问页面。
- 注册登录：新用户注册后可以登录，错误密码登录失败。
- PDF 上传：上传论文后文件保存到指定目录，数据库产生 paper 记录。
- 文献列表：前端显示上传论文的标题、作者、年份、状态、标签。
- 文献详情：点击列表项可以进入详情页。
- Git 记录：每人至少 2 次 commit，至少 1 次 merge。
