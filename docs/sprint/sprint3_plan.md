## 6. Sprint 3 完成标准
- 文献关系图可以展示论文节点和关系边。
- 点击关系图节点可以查看论文详情。
- Agent 可以根据研究主题生成阅读路线、阶段任务和周计划。
- 综述辅助功能至少完成多论文对比或综述大纲。
- 完成系统测试、修复核心 bug。
- 完成本地部署或 Docker 部署。
- 完成最终 Pre PPT、演示脚本和演示数据。
