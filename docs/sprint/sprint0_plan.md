# Sprint 0 计划

## 1. Sprint 目标

完成 AI 驱动的科研文献分析平台的项目立项、需求分析、敏捷规划和 Git 协作环境搭建。

## 2. 时间范围

2026 年 7 月 10 日 - 2026 年 7 月 13 日

## 3. 团队分工

| 成员 | 角色 | Sprint 0 任务 |
|---|---|---|
| 成员 A | 组长 / 后端负责人 | Git 仓库、分支、Issue、技术架构、数据库设计、Sprint 计划 |
| 成员 B | AI 负责人 | PDF 解析调研、AI 总结、问答、Agent 规划方案 |
| 成员 C | 前端负责人 | 页面原型、用户流程、前端技术选型 |
| 成员 D | 测试与文档负责人 | 需求文档、测试计划、周报、汇报材料 |

## 5. Daily Scrum 安排

每天晚上 21:30 进行 10 分钟线上 Daily Scrum。

每个人回答：
1. 昨天完成了什么？
2. 今天准备完成什么？
3. 遇到了什么问题？

## 6. Sprint 0 完成标准

- Git 仓库已创建
- develop 和 feature 分支已创建
- Issues、Labels、Milestones、Project Board 已创建
- 需求分析文档初稿完成
- 技术架构文档完成
- 数据库设计初稿完成
- AI 模块调研完成
- 前端原型完成
- 测试计划初稿完成
- 第一次汇报材料完成
